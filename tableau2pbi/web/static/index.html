Validate numbers

Every Tableau worksheet is executed with Tableau semantics and its converted Power BI visual is executed with DAX semantics, over the same source data. Results are compared cell by cell. Checks run in four layers: metadata parity, data reconciliation, visual reconciliation, and scenarios (parameter changes and slicers).
